# Rosyjski dla Polaka

Aplikacja (PWA) do nauki języka rosyjskiego dla osób polskojęzycznych.

- **Ścieżka A1 → C2**: 47 lekcji, prawie 700 słów, każde z zaznaczonym akcentem; kolejna lekcja otwiera się po poznaniu 70% poprzedniej albo po zdanym teście.
- **Trening z automatycznym sprawdzaniem**: najpierw karta ze słowem, potem sprawdzenie: ABCD w obie strony, zdanie z luką, rozpoznawanie ze słuchu, wpisywanie (klawiatura ЙЦУКЕН). Powtórki układa algorytm SM-2.
- **Słuchanie**: słowa, zdania, pisownia ze słuchu, „prawda czy fałsz”, czytanki A2–C2.
- **Wymowa**: akanie (о czy а?), ы/и, twarde i miękkie spółgłoski, akcent.
- Alfabet z transliteracją, fałszywi przyjaciele, gramatyka kontrastowa (m.in. czasowniki ruchu), dialogi z shadowingiem, dyktando.

Budowanie: `python build.py` → `Rosyjski_dla_Polaka.html` (jeden plik) i `docs/` (GitHub Pages / instalacja na telefonie).
